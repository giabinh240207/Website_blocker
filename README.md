# Website Blocker

Script Python chặn các trang web gây xao nhãng (TikTok, Instagram, Threads...) bằng cách chỉnh file hosts.

## Cách chạy

Script sửa file hosts nên cần quyền quản trị:

    sudo python3 src/website_blocker.py

Trên Windows, hãy mở terminal bằng quyền Administrator rồi chạy `python src/website_blocker.py`.

## Chức năng

1. Chặn ngay
2. Bỏ chặn tất cả
3. Chặn đến một giờ nhất định
